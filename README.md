Falling Sand Game
A pixelated game with an incremental game loop (non-continuous), with various materials that can interact with each other.

Key Features:
* Density System: Denser objects sink in less dense objects (eg: sand in water)
* Immovable objects, gaseous particles (that rise up) and sand-like particles and liquid particles (that fall down)
* Flammability for objects like wood, catching fire when contact with fire particles
* Fire particles produce smoke after a short while; fire particles can be extinguished using water, which releases steam into the air
* Acid, which is a liquid, which corrodes other particles at a speed based on their resistance to acid corrosion
